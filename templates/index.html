ReportSaathi: Architectural Overview

Slide 3: Technical Implementation Pipeline

1. Upload: Photo or PDF of lab report
2. Prepare: Pillow cleanup, PyMuPDF
3. Extract: OCR test names, values, ranges
4. Rules Engine: Python deterministic compare
5. Explain: Curated MedlinePlus dictionary
6. Accessible: Hindi/English TTS audio readout
Key Innovation: Rules First, AI Second

Status (HIGH, NORMAL, LOW) comes from strict deterministic code comparing value with printed range. The AI never guesses numbers and strictly explains concepts.

Safety Guard: No Autonomous Diagnosis

Fixed prompts, output checker, and WHO-aligned refusal guard send diagnostic questions back to qualified doctors.
